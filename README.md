[make.fun bounty](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521).

## The entry

> My fridge light died months ago, so dinner is now a trust exercise between me and whatever's growing in the back.

## How it works

`main.py` (Python 3, stdlib only) writes that single line — 113
characters, one line, nothing else — to the output path:

- `$ENTRY_OUT` (a file, or a directory, in which case `entry.txt` is
  written inside it)
- `$MAKEFUN_OUTPUT_DIR` (the kit harness directory)
- `$ENTRY_OUT_DIR`
- otherwise `/output/entry.txt`

Run it:

```sh
ENTRY_OUT=./out python3 main.py
```
